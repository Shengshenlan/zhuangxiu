## 本版排布

上方客餐区放两个错开的工位与小餐桌，下方客厅保留沙发、电视与猫的活动路线。次卧释放为偶尔留宿和补充收纳。房间分隔沿原户型保留，客厅后加隔间不再画入。

| 位置 | 本版拟定尺寸（cm） | 使用安排 |
| --- | --- | --- |
| 双屏工位 | 桌面160×70 | 沿客餐区上方墙，放两块显示器与一台主机 |
| 单屏工位 | 桌面120×70 | 沿次卧外侧墙，避开次卧门洞，放一块显示器与另一台主机 |
| 餐区 | 桌面80×60 | 两人日常用的小餐桌；需要多人用餐时再考虑移动或扩展 |
| 下方客厅 | 沙发约200×90，电视柜130×36 | 沙发与电视分置两侧，中央不放大茶几，仅安排侧几 |
| 主卧床 | 床垫180×210；示意床架184×218 | 床头靠主卧左侧墙；床长可切换为200cm比较 |
| 主卧挂衣区 | 宽130、深55；顶柜离地约210～260 | 顶柜＋挂衣杆＋帘子，集中在上方墙的门洞旁 |
| 主卧梳妆台 | 64×40 | 靠右上侧墙，示意凳子使用后收至台下 |
| 次卧客床 | 床垫100×200；示意床架106×206 | 低频留宿，后补采购；具体床形式及留宿人数待确认 |
| 次卧收纳 | 宽100、深50 | 本版建议补充储物，尤其主卧衣物量较多时 |
| 厨房 | 地柜深60、台面高约85 | 基础L形地柜，冰箱左上，灶台与水槽靠右 |
| 已有小家电 | 电饭锅、空气炸锅 | 保留使用，模型在南侧短柜台面摆放；实际外尺寸尚未提供 |
| 洗碗机 | 先按60cm宽柜位 | 机器后买；柜位、进排水和电源先按候选型号规划 |
| 机器人 | 基站约55×60 | 放卫生间外侧上方墙边；可后买，安装规格与接口待定 |
| 阳台洗烘机 | 约62×64 | 右端摆放，机门朝阳台长边；生活污水接口、电源与安装条件待核 |
| 养猫 | 猫砂盆在阳台左端 | 食水区放客厅，另安排猫爬架与活动路线；开窗防护需另定结构 |
| 入户鞋柜 | 窄翻斗柜约35×24 | 入户门旁小占位，避开门扇；实际鞋量与大尺码鞋适配待核 |

这些尺寸是本版方案建议，不是采购订单，也不是已增加的合同工程量。预算仍以[预算说明](../预算/装修预算_20261006.md)与Excel为基准；家具、家电具体产品确定后再替换占位。

## 紧凑位置

- 上方餐区：小餐桌与厨房一侧约有75cm通道。两个工位的座椅虽错开，实际座椅体积、椅子后退及两人同时起身进出仍需复尺；不能直接换成长餐桌或更深电脑桌。
- 主卧：长床方案床脚约63cm，换180×200cm床垫时约73cm。此数值按窄边示意床架计算；不同床头、床尾会改变结果。
- 主卧窗前约15cm，需核对窗帘厚度、开窗与清洁方式。挂衣区前方约81cm，仅安排130cm宽主卧挂衣区；衣物量未盘点，次卧收纳是本版补充建议。
- 阳台仅1.09m深，洗烘机朝长边开门；具体型号尺寸、散热、机门、检修及上下水可行性必须现场核对。

| 事项 | 建模依据 | 尚未确认 |
| --- | --- | --- |
| 主卧、次卧、厨房、阳台净长宽 | 按现有尺寸文件输入 | 图面尺寸非现场实测 |
| 客餐厅下方净宽 | 原图标注3.05m | 整个客餐厅是非矩形，模型近似边界面积约25.91㎡，原图标注25.6㎡ |
| 卫生间 | 原图标注2.79㎡，按凹角形态近似描绘 | 没有完整净长宽，不能把模型凹角边长当成实测值 |
| 整体外轮廓 | 参考9.25×9.12m外尺寸及原图房间关系 | 图面局部比例与标注并不完全一致，优先保留已知房间净长宽 |
| 墙厚与门窗 | 为连接图面使用约12～25cm墙厚、约80～88cm房门等占位 | 真实墙厚、门洞、窗宽、窗台、开启方式全部待测 |
| 净高 | 用户自述约2.7m | 实测高度、局部梁与管道未提供 |
| 光线、材质、颜色 | 用于辨认地面和家具 | 朝向未知，没有进行日照或真实照明模拟 |
| 拆除 | 方案中移除客厅后加隔间 | 现场核对可拆范围和结构；不能根据模型判断承重 |
| 设备接口 | 按需求预留位置 | 生活污水接口、燃气排烟、管路、电源及设备安装条件均待核 |

标注面积与净长宽乘积可能不同。例如主卧图上9.94㎡，2.83×3.37m约9.54㎡；本模型优先使用净长宽排家具。已标空间面积54.4㎡不是整房已实测套内面积，也不能直接作为施工计价面积。

## 查看方式

- 拖动模型旋转，滚轮或加减按钮缩放；手机单指旋转、双指缩放。
- 左侧或上方房间按钮聚焦对应空间；点击房间或家具也可选择。
- “俯视”便于核对位置，“尺寸”显示主要净宽与床脚通道。
- 墙体可剖切、显示约2.7m整高或隐藏。剖切高度只为看清家具，实际房间高度没有被缩短。
- “后补设备”可显示或隐藏电视、客厅空调、机器人、洗碗机和客床。水电与柜位仍需先规划。
- 床长切换为180×200cm只作尺寸比较，不代表已修改用户需求。

## 核对结果与下一步

已按图面净尺寸核对四个矩形房间；各项家具占位均落在对应房间边界内，门扇路径已检查。柜位中的洗碗机与墙挂电视的投影重叠为预期的嵌入关系。旋转、缩放、房间选择、床长切换、后补设备及墙体状态已做交互逻辑验证，并检查了三维、俯视和窄屏模型渲染。

下一步应由装修公司复尺并排入最终家具外尺寸，重点核对上方工位餐区、主卧窗帘与床脚、衣物收纳量、阳台生活污水接口，再形成点位图和同口径全包报价。
