## 方案与预算

两单屏工位靠阳台两侧；固定120×70cm餐桌、沙发和电视位置保留。入户214cm组合鞋衣柜，主卧182cm衣物柜区分干净、复穿、待洗衣物，次卧110cm柜补收纳，柜底柜顶收口。床沙发最低梁16cm，电视柜底18cm，次卧梳妆台底66cm。架空与封底均需结合实物和设备检修。

| 阶段 | 项目规划 | 资金准备 |
| --- | --- | --- |
| 硬装施工 | 89660 | 101260（含应急金11600） |
| 入住必需 | 26340 | 26340 |
| 入住后补 | 14000 | 14000 |

入住前资金127,600元，完整规划141,600元；电脑和游戏主机不计，八处扩充吊柜5,500元及其他可选默认不计。价格尚未询价，工程量与机型按现场复核。吊柜若做应在硬装期决定并核固定，不能等后期随意挂装。
