## 当前安排

- 两个单屏工位靠阳台两侧，主机离地、插排进桌下走线槽；沙发底16cm、电视柜悬空18cm。
- 固定餐桌120×70cm；入口214×42cm柜分鞋柜、外套挂位、换鞋座与杂物。
- 主卧182cm柜分干净挂衣与独立待洗仓；可复穿衣物挂在门扇以外的45cm壁挂板。柜体封底并封顶，次卧110cm柜补收纳。
- 16处灯具、37个电源插座、7组开关、4组网口已入模；普通插排只用于两工位，按实物额定负荷使用。
- 机器人按38cm直径/14cm高包络，通路45cm、家具下16cm预留。四种床头与床长组合各10条干区路径通过图面验算；门完全打开、椅子收近、阈高可通过是假设，湿区人工清扫。
- 首批115,100元＋机动11,600元=126,700元；后补14,000元，整体140,700元，区间111,600～178,200元。尚未取得正式报价。
- 扩充八处吊柜约7.96延米，4000～8000元、暂留5500元未计基准；全部首批实施含机动，整体146,700元。基础柜顶与厨房吊柜不重复计费。
